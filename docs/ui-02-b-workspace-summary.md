# UI-02-B — 여행 작업 공간 상단 요약

기준: S03 여행 작업 공간, 0-B 화면 명세 / Travel Editorial 1-A. 선행 UI-02-A Draft PR #18의 최신 커밋 `b01d0bd`를 기준으로 작업.

## 적용 범위

- 페이지 앱바를 '여행 작업 공간'으로 고정하고 상세 헤더의 여행명 중복을 제거.
- 본문 헤더는 여행명(최대 두 줄), 국가·도시, 현지 기준 여행 기간, 여행 상태, IANA 시간대·통화, 기존 목적·메모를 유지하여 한 영역으로 정리.
- '여행 한눈에' 요약을 헤더 아래에 한 개의 전체 테두리 패널로 배치. Compact에서는 1열, Medium·Expanded에서는 3개의 균형잡힌 정보 칼럼.
- '다음 일정': 현재 여행의 일정 목록에서 여행 시간대 기준으로 가장 가까운 미래 일정 표시. 오늘 시간이 지난 일정은 제외, 시각 미지정 일정은 해당 날짜의 후보로 유지. 없다면 '일정 미등록' 또는 '예정된 일정 없음'.
- '사용 경비': 기존 `calculateExpenseTotals()`의 기본 통화 합계 재사용. 미환산 외화는 더하지 않고 종류 수와 제외 사실을 안내. 예산 통화가 기본 통화와 일치할 때만 사용률 계산, 다르면 비교 불가 안내. 예산이 없으면 미설정 표시.
- '준비물 완료': 현 여행 로컬 체크리스트의 완료 건수/전체 건수와 완료 비율 표시.
- 모든 값은 현재 `tripId`에 종속된 Room Repository Flow로 갱신. 원격 환율·가상 데이터·새 의존성 없음.

## 명시적 비변경

- 기존 지도·일정·경비·준비물·정산·예약·동행자 진입 버튼, 편집/삭제 확인, Room v5, 개인정보처리방침, Play 배포 설정은 변경하지 않음.
- '열기' CTA와 태블릿 작업 공간 카드 2열 전체 구조 재설계는 UI-02-C 단계.
- Travel Editorial의 흑백·회색 및 네 면 테두리 기준 유지; 그림자, 라운드, 그라데이션, 애니메이션 없음.

## 자동 검증

- Unit: 다음 일정의 여행 현지 시간대 기준, 지난 일정 제외, 시각 미지정 일정, 날짜·시간·기존 정렬 순서, 빈 목록.
- Android API35 CI: Debug 빌드/JVM·Room 계측, 2-C 화면 QA, 3-A 지도 QA, 3-B 정산·예약 QA.
- 2-C 실제 UI: '여행 한눈에', '다음 일정', '사용 경비', '준비물 완료' 탐색 및 샘플 KRW 12,500/준비물 1/3 확인. 라이트·다크·160% 글꼴 상태 상단 실제 PNG 별도 캡처.
- PR에는 변경 커밋의 CI 결과와 실제 원본 PNG를 확인한 후 완료 여부를 기록. 수동 실기기·TalkBack·폴더블/Play 게시를 자동 QA로 대체하지 않음.

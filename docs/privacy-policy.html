TripCanvas 개인정보처리방침

시행일: 2026년 11월 9일

TripCanvas는 여행 일정·장소·준비물·경비를 사용자의 Android 기기에 저장하는 앱입니다. 이 방침은 현재 제공하는 기능에 적용됩니다.

기기에 저장하는 정보

사용자가 입력한 여행 이름·날짜·국가·도시·메모, 일정과 장소, 준비물, 예산·지출·통화 정보는 앱 내부 데이터베이스에 저장됩니다. 앱 테마와 시작 안내 설정은 기기에 저장됩니다. 개발자는 이 내용을 전달받거나 열람하지 않습니다.

외부 전송과 계정

현재 앱은 로그인, 광고, 분석, 결제, 개발자 서버 업로드, 자동 클라우드 동기화 기능을 제공하지 않습니다. 앱에 인터넷 접근 권한을 선언하지 않으며 여행 정보를 개발자 서버로 전송하지 않습니다.

백업과 복원

사용자가 백업을 요청하면 Android 시스템 파일 선택기로 지정한 위치에 여행·일정·장소·준비물·경비 JSON 파일을 저장합니다. 복원 시 사용자가 선택한 백업 파일을 읽습니다. 백업 파일은 암호화되지 않으며 개인 메모와 지출 정보가 포함될 수 있으므로 안전한 위치에 보관하고 공유에 주의해 주세요. 사진·첨부파일·앱 테마 설정은 백업 대상이 아닙니다.

시스템 파일 선택기에서 사용자가 외부 저장 서비스를 선택한 경우 해당 서비스의 저장·전송·보관에는 그 서비스의 약관과 개인정보처리방침이 적용됩니다. 이는 개발자 서버에 의한 자동 수집이나 동기화 기능이 아닙니다.

권한과 보관·삭제

현재 앱은 위치·마이크·연락처·광범위한 사진 또는 저장소 권한을 요청하지 않습니다. 사용자가 선택한 파일에만 시스템 파일 선택기로 접근합니다. 앱 내부 여행 자료는 해당 자료를 삭제하거나 앱 데이터를 삭제하거나 앱을 제거할 때 삭제됩니다. Android 자동 백업은 사용하지 않습니다. 외부에 저장한 백업 파일은 앱 제거로 삭제되지 않으므로 사용자가 저장 위치에서 직접 삭제해야 합니다.

TripCanvas 개인정보처리방침

시행일: 2026년 11월 10일

TripCanvas는 여행 일정·장소·준비물·경비·동행자 정산·예약 정보를 사용자의 Android 기기에 저장하는 앱입니다. 이 방침은 현재 제공하는 기능에 적용됩니다.

기기에 저장하는 정보

사용자가 입력한 여행 이름·날짜·국가·도시·메모, 일정과 장소, 준비물, 예산·지출·통화, 동행자 이름·결제자·분담 금액, 직접 입력한 환율·기준일, 예약 종류·명칭·일시·예약 확인번호·메모는 앱 내부 데이터베이스에 저장됩니다. 사용자가 연결한 예약 PDF·이미지 파일의 URI 및 표시 이름도 기기에 보존되며 원본 파일은 사용자가 선택한 제공자에 남습니다. 앱 테마와 시작 안내 설정은 기기에 저장됩니다. 개발자는 이러한 로컬 기록을 전달받거나 열람하지 않습니다.

외부 전송과 계정

현재 앱은 로그인, 광고, 분석, 결제, 개발자 서버 업로드, 자동 클라우드 동기화 기능을 제공하지 않습니다. 여행 일정·경비·준비물의 전체 기록을 개발자 서버로 전송하지 않습니다. 다만 아래 지도·장소 검색 기능의 제공을 위해 인터넷 연결을 이용합니다.

지도·장소 검색을 위한 외부 통신

저장한 장소를 지도에서 열면 지도 화면에 필요한 타일과 스타일을 OpenFreeMap 서버에서 가져옵니다. 이 과정에서 접속 IP 주소, 요청 시각, 표시하는 지도 영역에 해당하는 타일 좌표 등 일반적인 접속 정보가 지도 제공자에게 전달될 수 있습니다. 별도 동의 없이 기기의 현재 위치를 수집하거나 지속적으로 추적하지 않습니다.

사용자가 '외부 장소 검색' 화면에서 검색 버튼을 누른 경우에만 입력한 검색어가 Photon(komoot) 공개 검색 서버로 전송됩니다. 검색 결과의 장소명·주소·좌표·공급자 식별자 및 조회 시각 중 사용자가 저장하기로 선택한 정보는 해당 여행의 기기 데이터베이스에 저장되고, 백업 파일에 포함될 수 있습니다. 검색어 자동완성이나 백그라운드 검색은 수행하지 않습니다.

지도·검색 제공자의 서버 접속 기록 관리와 보존 기간은 해당 제공자의 운영 정책에 따릅니다. 관련 정보는 OpenFreeMap, Photon(komoot)에서 확인할 수 있습니다. 지도·검색 연결 없이도 사용자가 직접 등록한 여행·장소·일정·준비물·경비를 관리할 수 있습니다.

백업과 복원

사용자가 백업을 요청하면 Android 시스템 파일 선택기로 지정한 위치에 여행·일정·장소·준비물·경비·환율·동행자·분담·정산·예약 메타데이터를 JSON 파일로 저장합니다. 복원 시 사용자가 선택한 백업 파일을 읽습니다. 백업 파일은 암호화되지 않으며 예약 확인번호, 동행자 이름, 개인 메모 및 지출 정보가 포함될 수 있으므로 안전한 위치에 보관하고 공유에 주의해 주세요. 예약 원본 PDF·이미지와 그 파일 URI, 사진·앱 테마 설정은 백업에 포함되지 않으며 복원 후 사용자가 원본 파일을 다시 연결해야 합니다.

시스템 파일 선택기에서 사용자가 외부 저장 서비스를 선택한 경우 해당 서비스의 저장·전송·보관에는 그 서비스의 약관과 개인정보처리방침이 적용됩니다. 이는 개발자 서버에 의한 자동 수집이나 동기화 기능이 아닙니다.

권한과 보관·삭제

앱은 지도·검색 접속을 위한 인터넷 및 네트워크 상태 권한을 사용하지만, 기기의 위치·마이크·연락처·광범위한 사진 또는 저장소 접근 권한을 요청하지 않습니다. 사용자가 선택한 파일에만 시스템 파일 선택기로 접근합니다. 앱 내부 여행 자료는 해당 자료를 삭제하거나 앱 데이터를 삭제하거나 앱을 제거할 때 삭제됩니다. Android 자동 백업은 사용하지 않습니다. 외부에 저장한 백업 파일은 앱 제거로 삭제되지 않으므로 사용자가 저장 위치에서 직접 삭제해야 합니다.

# 3-B — 환율 스냅샷·동행자 정산·예약 자료

## 제품 범위
- 여행별 로컬 참가자 UUID 관리(동명이인 허용). 다른 여행의 분담/결제자 참조 차단
- 지출별 직접 입력 환율·기준일·사용자 입력 출처 영구 스냅샷. 실시간 시세 API 미사용
- 외화 미환산 지출은 기본 통화 합계 및 정산에서 제외
- 참가자별 균등·지정 금액·비율 분담을 `BigDecimal`과 통화 최소 단위로 검증
- 순지불액·순부담액으로 정산 제안 표시. 확인은 지문으로 보존하며 금액·환율·분담 수정 시 재확인 필요
- 예약 명칭·종류·현지 일시·확인번호·메모 CRUD, Android 시스템 문서 선택기 PDF/이미지 참조
- 실제 송금, 항공·숙소 결제, 계정·원격 초대는 수행하지 않음

## 데이터·백업
- Room v4→v5: `trip_participants`, `expense_shares`, `trip_settlements`, `bookings`, `booking_attachments` 추가, `expenses`에 결제자와 환율 메타데이터 추가
- 기존 Room v1/v2/v3/v4에서 v5로 데이터 이전. 삭제 재생성 기반 마이그레이션 금지
- JSON 백업 포맷 v3: 로컬 참가자, 지출별 환율·분담, 정산 확인, 예약 메타데이터 지원. v1·v2 읽기 유지
- 예약 PDF/이미지 **원본과 URI는 백업 제외**. 복원 뒤 파일 선택기를 통한 재연결이 필요
- 백업 JSON은 암호화되지 않으며 예약 확인번호·동행자 이름·지출 메모가 포함될 수 있음

## UI
- 작업 공간 → 동행자 관리·정산·예약 자료
- 지출 → 환율/분담 설정 → 정산 제안·완료 확인/철회
- 예약 목록은 확인번호를 숨기고 예약 편집에서만 표시. 파일 연결 제거는 원본 파일 삭제가 아님
- 기존 Travel Editorial 모노톤·라이트/다크·글꼴 160% 반응형 유지

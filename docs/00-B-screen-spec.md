# TripCanvas — 0-B 상세 화면 및 인터랙션 명세 v1.0

- 기준일: 2026-11-09
- 상태: 0단계 화면 정보 구조·입력·동작·상태·반응형 기준 정의 완료
- 기능 기준: [0-A 제품 요구사항](./00-A-product-requirements.md)
- 대상: Android 휴대폰, 태블릿, 폴더블. 디자인 방향: Travel Editorial
- 이 문서는 화면 설계서이며 이미지 목업·Android 스크린샷·구현 완료를 뜻하지 않는다.

## 1. 정보 구조와 기본 탐색 정책

핵심 탐색 구조는 홈(여행 목록) → 여행 상세(작업 공간) → 여행의 개별 기능이다. 모든 기능을 전역 하단 내비게이션으로 중복 나열하지 않는다. 여행 작업 공간은 맥락과 개발 단계에 맞는 1차 탭/링크를 제공한다.

- 홈: 전체 여행 목록, 상태별 필터, 새 여행, 설정.
- 여행 작업 공간: 상단 여행명/기간/목적지/상태/대표 이미지, 핵심 요약, 주요 기능 진입.
- 여행 내부 1차 콘텐츠: 일정, 지도(P1), 경비, 준비물·예약 자료(P1).
- 보조 기능: 참가자(P2), 여행 중 모드(P3), 기록/리포트(P3), 설정/백업.
- 시스템 뒤로 가기: 현재 상세→여행 작업 공간→홈; 미저장 변경은 '계속 편집/변경 폐기/저장' 중 적절한 선택 제공.
- 깊은 링크 및 초대 링크(P2): 로그인·권한 확인 → 해당 여행/대상 화면; 만료/권한 없음 시 안전한 안내 화면.
- 로컬 P0: 로그인/회원가입 화면 노출하지 않음. 네트워크 연결 유무는 여행 목록·일정 사용의 전제 조건이 아님.

### 기본 화면 흐름

S01 홈 → S02 새 여행/편집 → S03 여행 작업 공간.
S03 → S04 날짜별 일정 → S05 일정 편집 → S06 장소 선택.
S03 → S07 지도 → S08 장소 상세 (P1).
S03 → S09 예산·경비 → S10 지출 편집 → S11 정산 (P1).
S03 → S12 준비물 / S13 예약 자료(P1) / S14 참가자(P2).
S03 → S15 여행 중 모드(P3) → S16 방문 체크인(P3) → S17 여행 기록(P3) → S18 리포트(P3).
S03 → S19 AI 제안(P4).
S01 → S20 설정·백업.
S21 공통 상태/동기화 충돌은 관련 화면에서 모달 또는 전용 전체 화면으로 연결.

## 2. 공통 UI 프레임과 디자인 기준

### 2.1 스타일

- 콘셉트: Travel Editorial. 화이트·중성 회색·블랙 기반, 사진/지도는 실제 데이터로 시각적 초점 확보.
- 시스템 상태를 제외하고 의미 없는 강조색·그라데이션·장식형 그림자 사용 금지. 라운드는 컴포넌트 기능상 필요한 경우에만.
- 라이트/다크/시스템 모드 지원. 텍스트·배경·경계·상태 표시는 시맨틱 토큰 사용.
- 아이콘: 단색 선형 위주, 선 굵기·크기 일관성. 색만으로 완료/경고를 구별하지 않음.
- 타이포그래피: 화면 제목→섹션 제목→본문→보조 정보의 구분. 날짜·시간·금액 등 숫자는 고정밀 정렬에 적합한 스타일 적용.
- 숫자·날짜는 장치 로캘 및 여행 시간대 정책에 따라 표시하되 기준 통화·시간대를 항상 확인 가능하게 함.

### 2.2 공통 구성요소

TopAppBar(뒤로, 타이틀, 필수 행동, 더보기), TripHeader(목적지·기간), DateStrip(선택 날짜), TimelineItem, PlaceRow, ExpenseRow, CheckRow, StatusChip, EmptyState, ConfirmDialog, UndoSnackbar, OfflineBanner, SyncStatus, LoadingSkeleton, SaveBar, ErrorState.

공통 버튼 우선순위: 화면 전체에 주요 CTA는 1개, 일반 편집은 보조 텍스트/메뉴. 위험 작업은 확인 대화상자로 분리.

### 2.3 레이아웃·반응형

| 환경 | 배치 정책 |
| --- | --- |
| Compact (휴대폰) | 한 컬럼, 상단 앱 바, 필터/날짜 가로 스크롤, 주요 저장 버튼은 하단 접근 가능 |
| Medium (작은 태블릿/펼친 폴더블) | 목록·편집 또는 일정·상세 2분할 선택 지원, 수직 중첩 스크롤 최소화 |
| Expanded (태블릿) | 일정 리스트+지도, 지출 목록+요약, 장소 목록+상세 2~3패널. 좌측 정보·우측 미디어 원칙 |
| 글꼴 160% | 제목/버튼 말줄임 검토, 필수 라벨 자동 줄바꿈, 수평 스크롤 강요 없음 |
| 회전·힌지 | 중요한 버튼/폼/사진이 접힘 영역에 걸리지 않도록 창 크기·힌지 상태 기반 재배치 |

화면 폭 수치와 Compose WindowSizeClass 매핑은 1-A에서 실제 테스트 기기 기준 확정한다. 태블릿에서 바깥 화면과 사진 내부에 중첩된 별도의 수직 스크롤을 만들지 않는다.

## 3. 화면별 상세 요구사항

### S00 — 첫 실행 안내 [P0]

목적: TripCanvas의 주요 가치와 로컬 저장 원칙을 짧게 안내.

구성: 로고, 한 문장 소개, '여행 시작' CTA, '데이터는 우선 기기에 저장됩니다' 안내. 로그인/권한 요청 없음.
행동: '여행 시작' → S01. 첫 실행 안내는 다시 보지 않아도 진입 가능; 설정에서 앱 정보 확인.
상태: 최초 설치/기존 데이터 여부 식별. 시스템 다크 모드 즉시 반영.
수용: 네트워크 차단·권한 거부 상태에서도 S01 진입.

### S01 — 홈·여행 목록 [P0]

목적: 나의 여행들을 찾고 새로운 여행을 시작.

상단: 'TripCanvas', 설정 아이콘, 여행 검색/정렬 기능은 기본 목록이 충분하지 않을 때 고도화(초기 필수 아님).
메인: '예정', '여행 중', '완료' 필터 또는 섹션, 여행 카드(제목, 날짜, 목적지, 상태, D-day/기간 요약), 여행 생성 CTA.
행동: 카드 → S03, 새 여행 → S02, 메뉴에서 편집/삭제 → S02/삭제 확인.
상태: 0개 여행이면 '첫 여행을 만들어보세요'와 생성 버튼; 데이터 불러오기 오류 시 재시도/백업 복구 안내.
수용: 같은 이름의 여행을 여러 개 만들 수 있으나 ID로 구분; 날짜가 지나도 일정은 삭제되지 않음.

### S02 — 여행 생성·편집 [P0]

목적: 여행 기본 정보를 입력/변경.
폼 순서: 제목* → 시작·종료일* → 국가/도시 → 시간대* → 기본 통화* → 여행 목적/메모 → 대표 이미지(첨부 단계 후).
CTA: 신규 '여행 만들기', 편집 '저장'. 좌측 뒤로/취소.
검증: 제목 공백 제거 후 1~80자; 시작일<=종료일; 시간대·통화 유효 값. 오류 메시지는 입력란 하단에 이유/해결 방법 표시.
수정 정책: 기간 축소로 밖에 남는 일정은 감지해 변경 영향 안내; 사용자가 대상 날짜를 정리할 때까지 자동 삭제하지 않음.
상태: 신규/수정/미저장 변경/필드 오류/저장 중/DB 저장 실패.
수용: 2회 저장 방지, 취소 시 미저장 변경 경고, 완료 시 S03 이동(수정은 기존 경로 복귀).

### S03 — 여행 작업 공간 [P0, 단계별 확장]

목적: 여행별 요약과 관련 기능 허브.
헤더: 여행명, 도시, 현지 날짜·기간, 여행 상태, '편집' 메뉴.
상단 요약: 오늘 일정 수 또는 다음 일정, 예산 대비 지출, 준비물 완료/전체. 사용자가 아직 데이터를 등록하지 않았으면 값 미설정 표시.
핵심 진입: 일정(S04), 경비(S09), 준비물(S12). 이후 지도(S07), 예약(S13), 참가자(S14), 여행 중(S15), 기록(S17), 리포트(S18).
상태: 신규 빈 여행에서는 일정·준비물 추가로 유도. 오프라인 공동 여행에서 SyncStatus 표시(P2).
수용: 모든 기능 화면은 현재 tripId에 고정; 다른 여행 데이터가 섞이지 않음.

### S04 — 날짜별 일정·타임라인 [P0]

목적: 특정 일자의 일정 생성·배치·수정.
헤더: 여행명, 날짜 스트립, 이전/다음 날짜, 일정 편집 메뉴.
본문: 시간 지정 일정은 시각·제목·장소·예상 소요·메모 일부 순서; 시간 미정은 별도 구역. 경고 있는 항목에는 충돌 표시.
CTA: '일정 추가' → S05, 항목 탭 → S05, 길게 누르기/재정렬 핸들로 순서 변경.
행동: 다른 날짜로 이동, 복제, 삭제(확인/취소), 장소 선택 시 S08로 연결(P1).
상태: 빈 날짜, 겹치는 일정, 기간 마지막 날, 오프라인. 타임존 경고는 데이터 손실 없이 표시.
수용: 드래그 재정렬 후 앱 재실행해도 순서 유지, 같은 시간대 충돌은 경고만.

### S05 — 일정 추가·수정 [P0]

폼: 일정 제목* (1~100), 날짜*, 시작/종료(선택), 장소 연결(선택, S06), 메모, 중요 표시.
기본값: 현재 S04 선택 날짜. 시간 미정은 시작·종료 모두 비움. 날짜 변경 시 선택한 여행 기간 확인.
CTA: '저장'; 수정 시 '삭제', '복제'는 별도 메뉴.
검증: 종료가 시작보다 앞서면 저장 불가. 시간 범위가 기존 일정과 겹치면 '겹치는 일정이 있습니다' 경고와 '그래도 저장' 선택.
상태: 로컬 저장 실패, 빈 제목, 원본 일정이 삭제된 상태(P2), 편집 충돌(P2).
수용: 장소가 미등록이어도 일정 작성 가능; 사용자가 저장하지 않은 임시 입력은 별도 일정으로 생성되지 않음.

### S06 — 저장 장소 목록·선택 [P0 / P1]

목적: 기존 장소 연결 또는 신규 장소 직접 입력.
P0 목록: 현재 여행의 장소명/주소/메모 검색 및 선택, '새 장소 만들기'.
P0 생성: 장소 이름* (1~100), 주소/메모, 선택적 좌표. 장소 저장 후 이전 일정 폼으로 돌아가며 연결.
P1 확장: 외부 검색 탭/결과, 데이터 공급자 표시, 중복 후보 표시, 상세(S08)/지도(S07) 연결.
상태: 장소 0개, 같은 이름 다수, 공급자 검색 불가/네트워크 없음(P1).
수용: 검색 API 불가여도 수동 장소 생성 가능; 다른 여행 장소를 자동 참조하지 않음.

### S07 — 여행 지도·경로 [P1]

목적: 일정과 지도 사이를 전환하며 이동 동선 확인.
상단: 날짜 필터, 방문 후보/확정 핀 범례, 지도 검색, 이동수단 선택.
중앙: 지도 핀·순서, 선택 장소 상세 축약 카드, 지도↔일정 표시 전환.
하단/보조 패널: 날짜별 방문 순서·장소 리스트, 구간 이동 시간/거리(공급자가 제공한 경우), '일정에서 보기'.
행동: 핀 선택 → S08, 일정 선택 → 해당 핀으로 지도 이동, 경로 조회 → 공급자 데이터 표시.
상태: 좌표 없음(리스트에서는 표시, 지도 핀 생략), 네트워크 단절, API 할당량 초과, 경로 미지원 교통수단, 위치 권한 거부.
오프라인: 저장된 장소의 텍스트 목록과 좌표는 열람 가능. 공급자 라이선스 확인 없이 오프라인 지도 타일 보관을 약속하지 않음.
수용: 일정 변경 시 같은 tripId의 핀과 표시 순서가 일치; 계산 불가능한 경로 시간은 임의 추측하지 않음.

### S08 — 장소 상세 [P1]

구성: 장소 이름, 주소·지도 위치, 사용자 메모, 외부 데이터 공급자/조회일, 연결 일정 목록.
행동: 현재 선택 날짜의 일정에 추가 → S05로 복귀; 저장 장소 편집; 지도 열기.
상태: 폐업/조회 불가/중복 장소/좌표 없음; 미확인 운영 시간은 미표시.
수용: 외부 검색에서 같은 공급자 ID를 재선택하면 중복 저장 대신 기존 연결 제안.

### S09 — 예산·경비 홈 [P0 / P1]

목적: 지출 입력과 여행 예산 확인.
P0 상단: 기본 통화, 선택적 총예산, 지출 합계(환산 불가 통화 제외와 별도 표시).
P0 본문: 날짜별 지출 목록(금액·통화·분류·메모), '지출 추가' CTA.
P1 확장: 분류별 합계, 참가자별 지불·부담 내역, 환율 확인, 정산 화면(S11) 진입.
행동: 항목 → S10, 총예산 설정/수정, 필터.
상태: 지출 없음, 예산 미설정, 다른 통화 지출에 환율 없음, 삭제/저장 실패.
수용: 환율 없는 금액을 무단으로 기본 통화 지출 합계에 더하지 않음.

### S10 — 지출 추가·수정 [P0 / P1]

P0 필드: 금액* (>0), 통화*, 지출 날짜/시간*, 분류*, 메모, 선택적 장소.
P1 필드: 결제자, 분담 대상, 분담 방식, 각자 부담액, 환율 스냅샷, 영수증 첨부.
CTA: 저장; 편집 시 삭제(확인).
검증: 미입력·음수·0 금액 차단; 분담 확정 시 부담액 합계 일치. 다른 통화의 환율은 별도 확인 과정.
상태: 키보드 열린 상태에서 저장 버튼 접근 가능, 파일 첨부 실패, 분담 계산 오류.
수용: 지출 편집·삭제 후 S09 및 S11 합계 동시 갱신, 동일 저장 동작으로 이중 지출 방지.

### S11 — 동행자 정산 [P1 + P2]

목적: 각자 낸 금액과 최종 부담액을 구분해 비용 정산 확인.
상단: 여행 기본 통화, 정산 기준일, 미환산/미분담 지출 경고, 정산 완료 상태.
본문: 참가자별 결제액·부담액·순차액, '누가 누구에게 얼마' 제안 목록, 분담 방식 상세.
행동: 지출 상세(S10) 수정, 정산 완료 표시/철회, 변경에 따른 정산 재계산.
상태: 참가자 미등록, 환율 없음, 합계 불일치, 정산 후 금액 변경.
수용: 참가자/환산 금액을 정확히 표시하고 실제 송금하지 않음. P1에서는 로컬 참가자 정보만으로도 정산 가능하게 설계하며 계정·원격 초대는 P2에서 연동.

### S12 — 준비물 체크리스트 [P0]

구성: 전체/미완료 필터, 완료 수/전체 수, 체크박스 있는 목록, '준비물 추가' CTA.
행동: 체크 토글 즉시 저장, 항목명 편집, 순서 변경, 삭제(실행 취소 가능 범위), 미완료만 보기.
상태: 빈 목록, 전부 완료, 오프라인, 저장 실패.
수용: 다시 열어도 체크 상태 유지, 체크 해제 가능, 목록 정렬은 각 여행마다 독립.

### S13 — 예약·문서 자료 [P1]

목적: 예약 확인 정보를 여행에 연결.
목록: 종류별 항공·숙소·교통·입장권·기타, 날짜, 제목, 첨부 유무.
상세/편집: 예약명*, 유형*, 일정, 확인번호, 메모, 첨부 파일(이미지/PDF 등), 제거/교체.
행동: '자료 추가', 첨부 파일 선택기, 파일 열기, 연결된 일정 이동.
상태: 문서 접근 만료/삭제, 파일 없음, 지원하지 않는 MIME, 예약번호 노출 위험(공유 전 안내).
수용: 앱 내부 로그/공유 결과 기본값에서 확인번호 미노출. 파일 접근 실패가 예약 메타데이터를 삭제하지 않음.

### S14 — 참가자·공동 편집 [P2]

목적: 여행별 역할과 초대 관리.
구성: 소유자, 편집자, 열람자, 대기 중 초대, '참가자 초대' CTA, 변경 이력 진입.
행동: 초대 링크 생성·취소·수락/거절; 역할 변경, 참가자 제거, 본인 탈퇴.
권한: 소유자만 관리 액션. 편집자는 공동 데이터 수정. 열람자는 전체 편집 컨트롤 비활성화 및 서버에서 재검증.
상태: 미로그인(공동 기능 활성화 유도), 만료 초대, 권한 없음, 네트워크 없음, 계정 탈퇴 영향.
수용: 읽기 전용 사용자가 UI 우회로 데이터를 변경하는 시도도 거절.

### S15 — 오늘의 여행 [P3]

목적: 이동 중 자주 보는 최소 정보를 빠르게 노출.
상단: 현지 날짜, 다음 일정 카드(장소·시간), 진행 현황, 중요 예약 요약.
본문: 남은 일정 리스트, 방문 완료 표시, 빠른 지출 추가 버튼, 기록 추가 버튼.
행동: 일정 상세, 장소/지도 이동, 체크인(S16), 지출(S10), 사진 기록(S17).
상태: 오늘 일정 없음, 현지 날짜가 여행 기간 밖, 예약 정보 없음, 오프라인.
수용: 스크롤·과도한 조작 없이 다음 일정과 핵심 예약 정보를 찾을 수 있음. 사용자 체크인 전 자동 방문 완료 처리 금지.

### S16 — 방문 체크인 [P3]

구성: 장소/일정 제목, 기본 체크인 시각(사용자가 확인·수정), 메모, 완료 CTA.
행동: '방문 완료' 저장 → VisitRecord 생성, 일정 화면과 기록 목록 갱신.
상태: 동일 일정 중복 체크인, 일정이 삭제됨, 위치 정보 없음.
수용: 별도 위치 권한 없이 체크인 가능. 이전 방문 기록 수정은 별도 편집으로 처리하고 새로운 항목이 중복 생성되지 않음.

### S17 — 여행 기록·사진 타임라인 [P3]

목적: 실제 방문 장소와 사진·메모를 연결.
상단: 일자 선택, 장소별 보기 전환.
본문: 방문 타임라인, 기록 카드(사진 썸네일·장소·날짜·메모), '기록 추가'.
행동: 사진 선택기, 기록 메모 추가, 방문 기록 연결·해제, 삭제 확인.
상태: 사진 권한 거부(사진 선택기 기반 대안), 파일 경로 만료, 체크인 없는 사진, 오프라인.
수용: 사진 삭제가 별도 방문 데이터나 원본 갤러리 파일을 자동 삭제하지 않음. 태블릿은 목록+사진 미리보기 구조로 중첩 스크롤 제거.

### S18 — 여행 결과 리포트 [P3]

목적: 여행 종료 후 계획과 실제를 요약.
구성: 여행명·기간·목적지, 계획된 일정 개수/방문한 장소 개수, 지출 총액/환산 대기 금액, 대표 사진·방문 타임라인, 정산 요약.
행동: 내보내기(P4 상세), 공유 대상 정보 미리보기, 개인 기록 보관.
상태: 방문 기록/사진 없음, 미환산 지출, 첨부 파일 누락, 공유 취소.
수용: 미확정 경비는 정확한 값처럼 합산하지 않음; 공개 공유에 개인 예약번호·연락처 기본 제외.

### S19 — AI 일정·동선 제안 검토 [P4]

목적: AI가 만든 후보를 사용자가 직접 검토.
입력: 여행 기간/목적지(기존 여행값), 취향·이동 제약, 희망 일정 수.
출력: 제안 목록, 일정 충돌·이동 위험 표시, 확인되지 않은 운영 시간/거리 경고, 원본 대 제안 비교.
행동: 개별 항목 선택→편집→승인 반영. '전체 취소'로 원본 유지. 사용자가 승인하지 않은 데이터 변경 없음.
상태: AI 호출 실패·할당량 초과·오프라인·근거 부족·부분 생성.
수용: AI 텍스트를 예약 확정이나 검증된 운영 시간으로 표현하지 않음.

### S20 — 설정·백업 [P0 / 단계별 확장]

구성: 테마(라이트/다크/시스템), 기본 시간대·통화, 로컬 데이터 백업/복원, 개인정보·권한·앱 정보.
행동: '백업 내보내기' → Android 파일 저장 선택기, '백업 복원' → 시스템 파일 선택기 및 복원 미리보기/확인.
P2 확장: 계정, 동기화 상태, 탈퇴/데이터 삭제, 알림 설정.
상태: 파일 접근 거부, 잘못된 백업 버전, 기존 여행 중복, 저장공간 부족, 복원 도중 오류.
수용: 복원은 검증 후 원자적으로 적용; 오류 발생 시 기존 데이터가 손상되지 않음. 첨부 파일이 포함되지 않는 백업이면 범위를 명시.

### S21 — 공통 상태·동기화 충돌 안내 [P2 / 일부 P0]

- 저장 실패: 입력은 현재 폼에 보존, '다시 시도'/'취소' 제공. 성공 메시지를 실패 전에 노출하지 않음.
- 삭제 확인: 삭제 범위와 영향(일정/기록/동행자)을 보여줌. 위험 작업은 중립적 '취소'와 명시적 '삭제'를 분리.
- 권한 거부: 기능이 필요한 이유를 안내하고 선택기/수동 입력 같은 대안을 제공.
- 연결 끊김: 로컬 저장이 가능하면 정상 입력을 허용하고 '동기화 대기' 표시; 네트워크 필수 작업만 막음.
- 충돌 해결: 수정 대상, 내 수정/원격 수정 시각·변경 내용, '내 변경 사용'/'원격 변경 사용' 명시. 민감한 데이터는 미리보기에서 가림.
- 재시도: 중복 저장·이중 정산·복수 체크인 방지를 위한 안정적 처리.

## 변경 범위

- 날짜가 5일 이하인 여행: 모든 여행 날짜를 칩으로 한 번에 노출하고 별도 '다른 날짜 선택' 필드는 숨김. 기존 날짜 칩으로 모든 날짜 즉시 선택 가능.
- 6일 이상인 여행: 선택 날짜 앞뒤 2일의 날짜 칩 + 임의 날짜 선택기를 그대로 제공. 여행 시작/종료 범위 제한 유지.
- 선택한 여행 날짜 제목을 '11월 20일 · 금요일' 형식으로 표현(로컬 날짜의 한국어 요일).
- 시간 지정 일정: 시작 시각과 종료 시각을 왼쪽 고정 시간축에 정렬, 점과 중성 회색 세로 연결선으로 연속 일정 관계를 시각화. 카드 내부의 중복 시작 시각 라벨 제거.
- 시간 미정 일정: 기존 독립 섹션 및 카드 구조 유지. 선택된 날짜에 일정이 없으면 기존 빈 상태 안내.
- 일정 본문에는 제목 → 장소 → 메모 → 중요/확정/시간 겹침 상태. 기존 48dp 드래그 손잡이와 더보기 메뉴는 그대로 보존.

## 기능·데이터 불변

- Room 스키마, Repository 관찰·순서, 날짜/시간대·오프라인 동작, 장소 연결, 시간 겹침 판정 변경 없음.
- 일정 추가/수정/복제/정렬/삭제 확인, 지도/저장 장소 연결 및 접근성 명칭 변경 없음.
- 결제·정산·예약·준비물·백업, Play 트랙·서명·Google Play 스토어 자산 변경 없음.
- 새 라이브러리/네트워크 요청/애니메이션/그라데이션/그림자 추가 없음.

## 검증 기준

1. JUnit: 짧은 여행(1·3·5일)의 모든 날짜 칩, 장기 여행의 5일 창·임의 날짜 이동, 잘못된 날짜 범위 차단.
2. UIAutomator API35 phone/tablet: 실제 앱 진입, 선택 날짜의 한국어 표시, 시간축 시각 및 10:00 접근성 텍스트, 날짜 칩 변경, 빈 상태, 복제/충돌/정렬/삭제 확인, 연결 화면 진입.
3. 실제 라이트·다크·160% 원본 Android PNG에서 타임라인 연결선과 점, 숫자/제목/메뉴 겹침과 클리핑, 폭 좁은 폰과 태블릿 정렬을 시각 점검.
4. 정확한 PR HEAD에 대해 Android CI·JVM·Room35, 2-C phone/tablet, 3-A 지도 phone/tablet, 3-B 경비/예약 phone/tablet, API29/36 호환성 5종 CI 통과.
5. 실패 시 HEAD의 로그·스크린샷으로 원인 확인 후 재검증. QA 완료 전 Draft 유지 및 병합하지 않음.

물리 실기기, 폴더블/회전, TalkBack 수동 조작은 에뮬레이터 QA와 별도 미확인 영역이다. `main` 병합 후 기존 Play internal 자동 배포가 실행될 수 있으므로 정확한 AAB/Play API 결과와 Google 심사·테스터 설치를 구분한다. 이미 등록된 Alpha v10을 이번 단계에서 직접 승격/변경하지 않는다.

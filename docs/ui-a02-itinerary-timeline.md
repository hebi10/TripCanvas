## 변경 범위

- 날짜가 5일 이하인 여행: 모든 여행 날짜를 칩으로 한 번에 노출하고 별도 '다른 날짜 선택' 필드는 숨김. 기존 날짜 칩으로 모든 날짜 즉시 선택 가능.
- 6일 이상인 여행: 선택 날짜 앞뒤 2일의 날짜 칩 + 임의 날짜 선택기를 그대로 제공. 여행 시작/종료 범위 제한 유지.
- 선택한 여행 날짜 제목을 '11월 20일 · 금요일' 형식으로 표현(로컬 날짜의 한국어 요일).
- 시간 지정 일정: 시작 시각과 종료 시각을 왼쪽 고정 시간축에 정렬, 점과 중성 회색 세로 연결선으로 연속 일정 관계를 시각화. 카드 내부의 중복 시작 시각 라벨 제거.
- 시간 미정 일정: 기존 독립 섹션 및 카드 구조 유지. 선택된 날짜에 일정이 없으면 기존 빈 상태 안내.
- 일정 본문에는 제목 → 장소 → 메모 → 중요/확정/시간 겹침 상태. 기존 48dp 드래그 손잡이와 더보기 메뉴는 그대로 보존.

### 공통 개선

- `QaUiNavigator.kt`를 Android UIAutomator 테스트용 공통 네비게이터로 도입.
- 스크롤 가능한 실제 화면에서 클릭 대상의 부모 클릭 가능 여부, 화면 상·하단 안전 구간, 요소 무효화(`StaleObjectException`)를 재검증하여 누른다. 대상이 하단에 잘렸으면 노출 위치를 조정한 뒤 노드를 새로 조회한다.
- 예약 번호 보기/숨기기는 클릭 직후 변화된 버튼 라벨까지 반드시 확인한다. 클릭 후 상태 검증이 실패하면 원본 캡처·UI 계층을 남기고 실패 처리한다. 라벨 변화가 늦을 때 무조건 다시 눌러 반대로 토글하는 행동은 금지.
- 3-A 지도·3-B 정산/예약 UI 테스트에 동일 네비게이터를 적용. 2-C 테스트는 기존 성공한 저장·정렬·백업 회귀를 변경하지 않고, Android 테스트 APK가 컴파일되는지를 공통 CI에서 확인.
- `android-ci.yml`에 `:app:assembleDebugAndroidTest` 컴파일 게이트 추가. UI 테스트 Kotlin 구문·타입 오류를 에뮬레이터 검증 전에 발견할 수 있도록 한다. 다만 병렬 워크플로 자체를 모두 차단하는 의존성 구성은 아님.

### 병합/배포 안전 판정

- 변경 범위: UI-A02 일정 화면/관련 테스트 + 상기 QA 안정화 도구·테스트/CI 한정. Room·지도 프로덕션 로직·정산·예약·백업·서명·Google Play 설정은 변경 없음.
- 최신 동일 PR HEAD에서 **Android 빌드/JVM/AndroidTest 컴파일/Room**, **2-C phone/tablet**, **3-A phone/tablet**, **3-B phone/tablet**, **API29/36**이 모두 완료 성공해야 함.
- 라이트·다크·글꼴 160% 원본 PNG를 실제로 확인하고 잘림/가로 오버플로/터치 불가/비밀번호 노출 없는지 점검. GitHub Actions 성공만으로 실기기/폴더블·TalkBack·Play 심사 완료라고 기록하지 않음.
- 사용자가 요청한 작업 흐름 준수: 코드 반영 후 Checks URL 안내. GitHub Actions 결과 반복 조회를 하지 않고, 사용자가 완료를 확인해 후속 채팅을 보내면 최신 HEAD 검증·안전 병합·내부 테스트를 진행한다.

# UI-02-C — 작업 공간 기능 카드·태블릿 레이아웃 개편

기준: S03 작업 공간 / Travel Editorial 디자인 시스템. 이전 UI-02-B PR #19 HEAD `5446a3a`를 기반으로 구현.

## 변경 목적

UI-02-B 상단 요약은 그대로 유지하면서, 기능별 '열기' 버튼이 중복되어 공간을 차지하고 태블릿 양쪽 열의 높이가 불균형한 문제를 해결합니다. 사용자가 제목과 설명을 보고 카드를 직접 누르면 해당 기능으로 이동할 수 있도록 UI를 압축합니다.

## 화면·동작

- '작업 도구' 아래 8개 동일 규칙 카드: **일정, 지도, 경비, 준비물, 예약 자료, 동행자 정산, 동행자, 저장 장소**.
- 기존 작업 공간의 `onSchedule`, `onMap`, `onExpenses`, `onChecklist`, `onBookings`, `onSettlement`, `onParticipants`, `onPlaces`를 그대로 사용합니다.
- 작업 도구는 기능 우선순위 순서로 배치합니다. 기존 '저장 장소 관리' 하단 별도 버튼은 마지막 카드로 통합합니다.
- 카드 안의 반복된 '열기' 버튼은 제거. 카드 전체 터치 및 접근성 단일 조작 대상으로 노출.
- 접근성 이름은 기존 테스트에서 사용한 `일정 열기` / `지도 열기` / `경비 열기` / `준비물 열기` / `예약 열기` / `정산 열기` / `동행자 열기`와 `저장 장소 관리`를 유지합니다.
- 카드 크기는 최소 터치 높이 48dp 이상이며 실제 내용에 따라 늘어납니다. 글꼴이 160%여도 고정 높이로 자르지 않습니다.
- Compact: 모든 카드 1열, Medium·Expanded: 동일 너비 2열(4행). 기존 하나의 세로 스크롤 구조는 유지하며 가로/중첩 세로 스크롤을 만들지 않습니다.
- 카드 타이포는 현재 `MaterialTheme`와 `TripSpacing`을 사용하고, RectangleShape·사방 1dp outline·0dp 그림자를 유지합니다.
- 프리뷰 상태는 데이터 변경/화면 이동을 수행하지 않으며 카드가 비활성화됩니다.

## 안전·제외

- 기존 여행별 DB, 다음 일정·경비 합계, 준비물 완료율, 환율·정산, 지도 공급자, 예약 문서 접근, 편집/삭제, 백업, 개인정보처리방침은 변경하지 않습니다.
- 새 의존성·애니메이션·그라데이션·라운드·한쪽 테두리 없음.
- 기존 배포된 Play internal versionCode 2는 보존합니다.

## 검증

- Android CI: `assembleDebug`, JVM 단위 테스트, API 35 Room 이전/연결 계측.
- API 35 2-C 휴대폰·태블릿: 라이트·다크·160% 실제 PNG, '작업 도구' 섹션, 마지막 '저장 장소 관리' 접근성 노드 및 일정/저장 장소 카드 이동 → 뒤로 복귀, 기존 준비물/경비/백업 회귀.
- API 35 3-A: 지도 카드 → 여행 지도·핀·상세·일정 연결·검색 회귀.
- API 35 3-B: 동행자·정산·예약 카드 → CRUD 및 연결 회귀.
- CI의 최종 HEAD·성공 및 PNG 수량을 확인한 뒤에만 완료 표시. 첫 실패 시 로그·실제 화면·UIAutomator 노드를 확인합니다.
- 물리 실기기·TalkBack·폴더블 힌지 및 API29/36은 자동 API35 게이트와 구분해 후속 검증.

## 통합

UI-02-C는 UI-02-B PR #19 브랜치를 base로 하는 **Stacked Draft PR**입니다. UI-01 #17, UI-02-A #18, UI-02-B #19가 미병합인 동안 `main` 병합·Play 새 배포 금지. 전체 병합 시 선행 순서대로 기준을 최신 `main`으로 재설정하고 CI·스크린샷을 다시 검증해야 합니다.

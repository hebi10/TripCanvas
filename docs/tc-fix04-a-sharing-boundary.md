# TC-FIX-04-A — 공동 여행 범위·권한 준비 (2026-11-25)

기준 main 14441baefa82b13a028cecda51b80c1976c57ec4. 기존 COLLAB-00 및 PRD FR-COL-01~05/FR-SYNC-01~03/BR-08, S14·S21에 따른 선행 구현.

## 변경 범위
- 동행자 관리에서 정산용 로컬 참가자와 공동 여행 계정의 차이를 안내한다. 현재 로컬 여행 상태와 서버 미연결을 명시한다.
- 실제 데이터가 아닌 공유 후보 항목 및 역할의 읽기 전용 미리보기. 사용자 승인 없는 공유/초대/로그인/저장 상태 변경 없음. 예약 확인번호·첨부 문서·사진 원본·개인 메모의 공유 범위는 별도 확정. 검토 화면은 승인 기록이 아니다.
- 멤버 표시 사전 검증: 여행 및 현재 계정 일치, 서버가 검증한 조회 응답의 5분 이내 신선도와 만료/박탈 확인, 기존 OWNER/EDITOR/VIEWER 권한 정책. UI 사전 검사일 뿐 서버 권한의 증명이 아니다.
- 초대 후보는 소유자만 EDITOR/VIEWER로 생성, 자기 초대/소유권 부여 차단. 수락/거절 가능 표시는 정확한 여행·대상 계정·PENDING·만료 전 조건에서만 허용. 소유자 자기 제거 및 소유권 변경은 별도 정책 승인 전 차단.
- 향후 계정 매핑은 기존 로컬 참가자 ID의 일대일 연결만 검증하고 저장 데이터나 분담 행을 변경하지 않는다.
- gateway 계약에 초대 거절 추가. 미연결 gateway는 초대 생성/수락/거절/역할 변경/탈퇴/박탈/변경 제출을 모두 실패 처리.
- JVM 회귀 및 3-B 최종 화면 QA에서 공유 미리보기 진입·닫기, 기존 참가자와 정산 흐름 유지 검증 추가. Room 스키마/백업/정산 알고리즘 변경 없음.

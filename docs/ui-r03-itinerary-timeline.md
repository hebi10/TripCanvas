# UI-R03 — 일정·타임라인 리디자인

기준일: 2026-11-11. S04·S05 기존 0-B 기획서 및 UI-R00~R09 개선 계획, UI-R01 / UI-R02를 선행 기준으로 진행.

- UI-R01 PR #26 main 병합 커밋 `f684f38`.
- UI-R02 PR #27 `807576b1` Draft 및 QA 진행 중. UI-R03은 **UI-R02 브랜치 기반 stacked Draft PR**이며 UI-R02 병합·검증 완료 전 main 병합 금지.
- 시작 시 Google Play internal 최신 API 기록은 UI-R01 v5. UI-R03에서 Play 트랙/자산 수정하지 않음.

## UI 변경 사항

1. 날짜 탐색: 이전/다음 버튼과 날짜 칩의 중복 제거. 선택 날짜의 앞뒤 2일을 여행 날짜 범위로 제한한 날짜 칩(요일 포함)으로 표시; 장거리 이동은 기존 `TripDateField` 날짜 선택기를 '다른 날짜 선택'으로 유지.
2. 일정 추가: 화면 하단의 주 CTA를 날짜 탐색 바로 아래로 올리고 빈 상태의 중복 CTA는 제거. 사용자는 긴 타임라인의 아래까지 스크롤하지 않아도 새 일정으로 진입.
3. 타임라인: 실제 항목이 있는 시간 지정/시간 미정 그룹만 표시. 기존 시간 겹침·중요·확정 상태 태그 보존. 시각/제목/장소를 먼저 보여주고 긴 메모는 2줄 말줄임.
4. 카드 보조 조작: '수정/복제/위로/아래로/삭제' 5개 노출 버튼을 48dp 접근성 메뉴 하나로 통합. 위·아래 이동은 그룹 경계에서 비활성화. 드래그 손잡이는 유지하고 접근성 이름을 추가.
5. 삭제 확인, 복제 UUID/원본 유지, 정렬 Room 저장, 현지 날짜·시간, 다른 여행 격리 및 일정 충돌 경고는 변경하지 않음.
6. 일정 하단 '지도에서 보기'·'저장 장소 관리' 기존 진입 보존.

## 검증 항목

- JVM 날짜 칩 범위: 시작일·종료일·긴 여행의 5일 탐색·잘못된 범위·선택 범위 외 날짜.
- Android API35 실제 화면 QA: 기존 여행 작업 공간 → 여행 일정; 날짜 칩 이동/빈 상태/복귀; 메뉴 열기/복제/시간 겹침 표기; 메뉴 아래로 이동 후 DB 정렬 순서 확인; 삭제 확인/취소 후 2개 항목 유지. 증빙 PNG 수집.
- 회귀: 기존 2-C 홈·준비물·경비·백업 / 3-A 지도·장소 연결 / 3-B 정산·예약 / Room API35 / API29·36 및 개인정보 정책.
- 160% 글꼴과 휴대전화·태블릿 라이트/다크 화면의 아이콘/메뉴/CTA 잘림, 겹침, 긴 제목 접근성 검수.
- 물리 기기 및 TalkBack/폴더블은 실행한 범위만 완료 표시.

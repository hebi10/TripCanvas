## 암호화 형식
- 기본 권장 UI: 암호화 백업(.tcb), 비밀번호 설정/확인 후 SAF 저장. 기존 평문 JSON 내보내기와 복원은 명시적으로 유지한다.
- v1 envelope: ASCII TCBACKUP(8), version(1), salt(16), nonce(12), AES-256-GCM ciphertext + 128-bit tag. 헤더 전체 인증(AAD), PBKDF2-HMAC-SHA256 600,000회, SecureRandom으로 매번 salt/nonce 생성. 내부 JSON v4의 10MiB 상한 유지, 암호화 헤더/tag 추가 허용.
- 비밀번호는 사용자 입력 12~128자, saved-state/로그/DB/백업에 저장하지 않는다. 키·처리용 문자 배열은 가능한 범위에서 지운다. 분실 시 복구 불가. 특정 기기 Keystore에 묶이지 않으므로 비밀번호로 다른 기기에서 복원 가능하도록 설계했다.
- 인증 실패·잘못된 비밀번호·지원 외 버전·손상·초과 용량은 preview 거부. 검증된 snapshot의 최종 사용자 승인 전 Room 변경 없음. 기존 복원 트랜잭션 유지.

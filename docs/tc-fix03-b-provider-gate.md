# TC-FIX-03-B — 운영 장소 검색 공급자 승인 경계 (2026-11-25)

선행 PR #76 HEAD bda71c4888b5cb2f205369cec908007aa4141b0c 기반 독립 후속 Draft. #75 백업·복원, #76 지도 조회 개선 병합 및 최신 main 동기화 전 병합 금지.

## 구현
- Photon 공개 데모는 DEBUG 빌드에서 정해진 HTTPS 주소로만 사용자 명시 조회 시 접근 가능. 배포용 release 빌드에서는 서비스 및 화면 모두 공개 데모 호출을 차단한다. 내부 테스트도 release AAB를 쓰므로 현재 외부 장소 검색이 비활성화되는 것은 의도한 운영 안전 경계다. 저장 장소, 수동 등록, 저장 데이터 및 지도 스타일은 유지한다.
- 사용 불가 상태에 운영 공급자 미연결 안내와 이전 화면의 직접 등록 안내. 기존 #76 캐시/요청 간격/쿨다운·오류 보호 유지.
- JVM 정책 테스트 및 Android 계측에서 임의 endpoint 거부/네트워크 호출 전 차단 테스트 추가. 기존 화면 QA용 DEBUG 검색 필드는 유지.
- 실제 운영 서버 URL·서비스 계정·API 키·인증 토큰은 추가하지 않는다. 기존 경로 proxy의 기본 비활성 설정은 유지한다.

## 운영 공급자 연결의 선행 조건
1. 한국 및 해외 검색/경로 공급자 선정, 출처/저장·캐시 허용 조건, 서비스 약관 및 요금, 지원 이동수단 확정. 공개 데모 또는 승인되지 않은 무료 API를 운영용으로 사용하지 않는다.
2. 인증된 HTTPS 백엔드에서 /v1/places와 /v1/routes 등 계약 확정. 앱 사용자/설치 식별 검증, 서버 측 키 보관, 요청·동시성·일일/월간 한도, 비용 상한, timeout/429 및 로그 개인정보 최소화. 공급자 계약이 없는 임시 응답으로 실제 거리/시간을 표시하지 않는다.
3. 운영 장소 결과의 안정적인 공급자/공급자별 ID와 사용자 승인 후 저장, 기존 중복 방지 정책 및 데이터 호환. 앱 직접 키 삽입 금지.
4. 실제 API/서버 배포·비용 발생은 별도 승인. 승인된 운영 연결 및 실제 지역/오프라인/장애/개인정보/기기 QA 완료 전 TC-FIX-03 전체 완료로 표시하지 않는다.

이 PR은 공급자 선정이나 실제 서버 연결을 완료하지 않는다. Play 및 서버 배포 없음.

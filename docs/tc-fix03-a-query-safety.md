# TC-FIX-03-A — 지도·경로 조회 안전성 (2026-11-25)

기준 main: eefab18c808ee80b380fdc46f22a11752fc19ce8. TC-FIX-02-C PR #75와 독립적인 변경으로 선행 개발한다. 기존 Room 스키마, 여행 순서, MapLibre/OpenFreeMap 스타일, Photon 공개 데모(소규모 테스트용), 경로 프록시 기본 비활성 및 명시적 사용자 동의 정책 유지.

## 변경
- 장소 검색과 경로의 메모리 캐시를 각각 64개 LRU/10분으로 제한, 만료 항목 제거, Locale.ROOT 검색 키. 경로 캐시 적중도 원래 공급자 시각의 유효 범위를 재검증한다.
- 기존 최소 요청 간격 1.5초/1.2초 유지. HTTP 429 발생 시 Retry-After 초 또는 RFC1123 시각 기준으로 1분~24시간의 단말 세션 쿨다운을 적용. 재시도는 사용자가 명시적으로 실행해야 하고 자동 호출하지 않는다.
- 실제 경로 응답에서 정수형 거리·시간·조회 시각 및 문자열 공급자만 허용. 공급자 표시 이름 길이/제어문자 검사, 기존 10분/미래 1분 시간 경계 유지, 표시 계산 overflow 방지.
- 검색어 변경 시 기존 검색 결과를 비우고 이전 검색의 완료 응답은 무시. 외부 예외의 원문 대신 고정 오류 안내. 경로 재조회 시 이전 값 제거, 일정/장소 좌표/날짜/이동수단 변경 시 상태 초기화, 15초마다 로컬 만료 확인(네트워크 호출 없음).
- JVM 회귀: TTL/LRU, 요청 간격/쿨다운·Retry-After, 원래 조회 시각/공급자 유효성.
